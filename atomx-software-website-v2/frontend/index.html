01 / PLATFORM

Built around the operator’s next decision.

The software does not stop at “showing sensor values”. It turns field measurements into a traceable risk state, highlights the affected zone and keeps the alert history visible.

01
LIVE TELEMETRY

One screen for tilt, displacement, vibration and crack trend.

Each node keeps its identity, latest packet time, signal strength and local trend. Operators can drill into a node instead of reading a generic dashboard.

02
RISK ENGINE

Trend-aware risk state

Correlates multiple parameters and surfaces the reason behind an elevated state.

03
ZONE VIEW

Spatial context

Pinpoints which monitoring zone needs inspection rather than raising a mine-wide generic warning.

04
INCIDENT LOG

Acknowledge and export

Alerts can be acknowledged and exported with the current sensor snapshot for review.

02 / WORKFLOW

From movement in the field to a visible warning.

The demo below follows the same path intended for the hardware prototype. Use the controls to inject a safe or dangerous condition.

01Sense

Node samples tilt, vibration and displacement.

02Transmit

LoRa packet reaches the edge gateway.

03Process

Gateway filters, buffers and forwards telemetry.

04Evaluate

Server calculates risk and checks anomalies.

05Warn

Zone state and alert queue update together.

Demo scenarios are simulated; hardware mode uses live API data.
